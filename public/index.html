Wake the server ↗

In the game, choose Multiplayer → Shinobi SMP → Join Server.

Before you join

Free hosting sleeps when nobody is playing. If the server is offline, open “Wake the server” and enter shinobi-eagler.falixsrv.me. Wait for startup, then try joining again.

Your first client download is about 31 MB. A keyboard and mouse work best.

First-time login & connection help

Pick a username you’ll keep. On your first visit, register with /register password password. Next time, use /login password. Choose a unique game password.

If the website is waking up, allow about a minute. If a game connection drops during a host restart, reconnect from Multiplayer. Saved multiplayer progress lives on the server.
