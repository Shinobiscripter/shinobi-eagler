School Server

Eaglercraft 1.12.2

How to join

  1. Click Play Eaglercraft and choose a username.
  2. Select Multiplayer → School Server → Join Server.
  3. Press T to open chat. The first time, type /register yourPassword yourPassword. On later visits, type /login yourPassword. Replace yourPassword with your own game password.

If the server is offline, wake the server using shinobi-eagler.falixsrv.me, wait for it to start, then join again. If this website is waking up, give it about a minute.
